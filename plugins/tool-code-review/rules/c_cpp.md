# C / C++ 评审规则

精确优先：只报能确证的缺陷；格式与命名由 formatter/linter 覆盖。

## 内存与生命周期

- `malloc`/`new` 的分配在所有路径（含错误路径）未释放；异常路径泄漏。
- `new[]` 用 `delete`、`new` 用 `free` 等释放方式不匹配。
- 释放后使用（use-after-free）、重复释放、返回局部变量地址/引用。
- 数组越界读写、`strcpy`/`strcat`/`sprintf`/`gets` 等无边界函数处理外部输入。
- 指针未判空即解引用；`memcpy` 长度为负或超出目标容量。

## 未定义行为

- 有符号整数溢出、除零、移位超过位宽或负移位。
- 未初始化变量/成员被读取；严格别名违规；越界 `reinterpret_cast`。
- 悬垂引用（容器扩容后保留的迭代器/引用）。
- 返回值非所有路径覆盖（非 void 函数缺少 return）。

## 并发

- 共享数据在无锁/无原子保护下读写；`atomic` 只保护了部分访问。
- 持锁执行 I/O、回调或长计算；锁顺序不一致导致死锁。
- 条件变量等待缺少 while 循环或被信号丢失。
- `volatile` 被误当作同步原语。

## 资源与错误处理

- 文件描述符、socket、锁、事务未在所有路径释放（RAII 未使用）。
- 检查了返回值却忽略错误码；错误路径继续使用无效句柄。
- `errno` 在被使用前被其他调用覆盖。

## 安全

- 命令拼接 `system()`/`popen()` 使用不可信输入。
- 路径拼接未校验 `..`；临时文件可预测名称。
- 未校验长度的外部报文解析（整数溢出导致的堆溢出）。
- 硬编码密钥/证书；日志输出敏感信息。
